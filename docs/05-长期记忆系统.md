# 长期记忆系统设计文档

> MemSkill：基于 Agent Skill 格式的长期记忆。分层漏斗检索 + 自我维护（合并/衰减遗忘）+ SQLite 存储。

---

## 1. 设计理念

**记忆即 Skill**：每条记忆是一个结构化对象，不只是文本块，而是包含 name/keywords/summary/triggers/raw_content/importance 的完整技能对象。

**三个核心原则**：
- **分层漏斗检索**：语义匹配 → LLM 摘要筛选 → 原始内容展开（成本最优）
- **自我维护**：定期合并同类记忆、依重要性与时间衰减遗忘
- **双轨向量**：优先用 LLM embedding，失败回退到字符 bigram TF-IDF

## 2. 数据结构

### 2.1 MemorySkill

```python
class MemorySkill:
    skill_id: str           # 唯一 ID（mem_YYYYMMDD_HHMMSS_xxxxxx）
    name: str               # 记忆名称（≤15字）
    keywords: List[str]     # 关键词（≤5个）
    summary: str            # 摘要（≤60字）
    triggers: List[str]     # 触发场景（≤3个）
    raw_content: str        # 原始对话内容（≤5000字）
    importance: int         # 重要性 1~5
    created_at: str         # 创建时间 ISO
    last_accessed_at: str   # 最后访问时间
    access_count: int       # 访问次数
    source_session_ids: List[str]   # 来源会话
    is_merged: bool         # 是否合并产物
    merged_from: List[str]  # 合并来源
    embedding: List[float]  # 向量
```

### 2.2 SQLite Schema

```sql
CREATE TABLE memories (
    skill_id TEXT PRIMARY KEY,
    name TEXT,
    keywords TEXT,          -- JSON
    summary TEXT,
    triggers TEXT,          -- JSON
    raw_content TEXT,
    importance INTEGER,
    created_at TEXT,
    last_accessed_at TEXT,
    access_count INTEGER,
    source_session_ids TEXT, -- JSON
    is_merged INTEGER,
    merged_from TEXT,        -- JSON
    embedding TEXT,          -- JSON（空列表表示无向量）
    active INTEGER DEFAULT 1 -- 软删除标记

```

## 4. 记忆写入流程

```
对话结束
    ↓
异步线程调用 add_memory(conv_text, session_id)
    ↓
1. _llm_extract(conv_text)        # LLM 提取结构化记忆
    ├── 判断是否值得记忆（skip 字段）
    ├── 提取 name / keywords / summary / triggers
    └── 评估 importance（1~5）
    ↓
2. 如果 skip → 返回 None
    ↓
3. _get_embedding(summary)        # 获取向量
    ├── 优先：LLM /v1/embeddings
    └── 失败：空列表（检索时回退 TF-IDF）
    ↓
4. 构建 MemorySkill 对象
    ↓
5. store.insert(skill)            # 写入 SQLite
```

## 5. 三层漏斗检索

```
用户输入 query
    ↓
┌─ 第一层：快速语义匹配 ─────────────────────────────┐
│  all_memories = store.list_active(limit=500)        │
│  query_emb = _get_embedding(query)                  │
│  for mem in all_memories:                           │
│      if embedding 可用:                             │
│          sim = cosine_vec(query_emb, mem.embedding) │
│      else:                                          │
│          sim = tfidf_similarity(query, mem.summary) │
│  取 Top-K（K=5），sim > 0.1                         │
└─────────────────────────────────────────────────────┘
    ↓
┌─ 第二层：LLM 细粒度筛选 ───────────────────────────┐
│  构建候选列表：                                      │
│    [0] 标题:XX | 摘要:XX | 关键词:XX                │
│    [1] ...                                          │
│  LLM 判断哪些候选真正相关                            │
│  返回 {"indices": [0, 2]}                           │
│  失败回退：取 importance 最高的 1~2 条               │
└─────────────────────────────────────────────────────┘
    ↓
┌─ 第三层：返回完整记忆 ──────────────────────────────┐
│  返回选中记忆（含 raw_content）                      │
│  更新 last_accessed_at + access_count               │
└─────────────────────────────────────────────────────┘
```

### 5.1 第一层：双轨向量

```python
def _first_layer_match(self, query, memories, k=5):
    query_emb = self._get_embedding(query)
    use_embedding = bool(query_emb) and self._embedding_ok

    scored = []
    for mem in memories:
        if use_embedding and mem.embedding:
            sim = cosine_vec(query_emb, mem.embedding)    # 稠密向量余弦
        else:
            text_b = mem.summary + " " + " ".join(mem.keywords) + " " + mem.name
            sim = tfidf_similarity(query, text_b)          # 字符 bigram TF-IDF
        scored.append((sim, mem))

    scored.sort(key=lambda x: x[0], reverse=True)
    return [mem for sim, mem in scored[:k] if sim > 0.1]
```

### 5.2 TF-IDF 回退相似度

```python
def _char_bigrams(text: str) -> Dict[str, int]:
    """对中文友好的字符 bigram 频次表。"""
    text = re.sub(r"\s+", "", text)
    freq = {}
    for i in range(len(text) - 1):
        bg = text[i:i + 2]
        freq[bg] = freq.get(bg, 0) + 1
    for ch in text:           # 单字也作为一元特征
        freq[ch] = freq.get(ch, 0) + 1
    return freq

def tfidf_similarity(text_a, text_b) -> float:
    return _cosine_sparse(_char_bigrams(text_a), _char_bigrams(text_b))
```

**为何不用 jieba 分词**：避免外部依赖，字符 bigram 对中文足够有效，且无需词典。

## 6. 记忆注入上下文

```python
def build_context_text(self, memories: List[MemorySkill]) -> str:
    """构建注入 LLM 的记忆上下文。"""
    if not memories:
        return ""
    lines = ["以下是你的相关长期记忆，供参考："]
    for mem in memories:
        lines.append(
            f"• {mem.name}：{mem.summary}"
            f"（关键词: {', '.join(mem.keywords)}）"
        )
    return "\n".join(lines)
```

### 7.2 合并同类

```python
def schedule_maintenance(self) -> Dict[str, int]:
    stats = {"merged": 0, "forgotten": 0}

    # 1. 合并：找相似度高的记忆对，用 LLM 合并
    all_memories = self.store.list_active(limit=500)
    for i, mem_a in enumerate(all_memories):
        for mem_b in all_memories[i+1:]:
            sim = self._compute_similarity(mem_a, mem_b)
            if sim > 0.75:   # 高相似度阈值
                merged = self._llm_merge(mem_a, mem_b)
                if merged:
                    self.store.insert(merged)
                    self.store.delete(mem_a.skill_id)
                    self.store.delete(mem_b.skill_id)
                    stats["merged"] += 1

    # 2. 衰减遗忘
    now = datetime.now(timezone.utc)
    for mem in self.store.list_active(limit=10000):
        score = self._forget_score(mem, now)
        if score < 0.2:
            self.store.delete(mem.skill_id)
            stats["forgotten"] += 1

    return stats
```

### 7.3 衰减评分

```python
def _forget_score(self, mem: MemorySkill, now) -> float:
    """遗忘评分（0~1），越低越该遗忘。"""
    # 因素：重要性、访问次数、时间衰减
    days = (now - parse(mem.last_accessed_at)).days
    time_decay = math.exp(-days / 30)          # 30天半衰期
    importance_factor = mem.importance / 5.0    # 重要性 1~5 → 0.2~1.0
    access_factor = min(1.0, mem.access_count / 5.0)  # 访问 5 次满分
    return 0.4 * importance_factor + 0.3 * access_factor + 0.3 * time_decay
```

    """维护完成提示。"""
    if stats.get("error"):
        self._add_bubble("assistant", f"记忆维护失败：{stats['error']}", is_user=False)
        return
    merged = stats.get("merged", 0)
    forgotten = stats.get("forgotten", 0)

        msg = f"记忆维护完成：合并 {merged} 条，遗忘 {forgotten} 条"

## 10. 踩坑记录

| 问题 | 根因 | 解决 |
|------|------|------|
| 记忆写入阻塞回复 | 同步调用 LLM 提取 | daemon 线程异步写入 |
| embedding 服务不可用 | LLM 不支持 /v1/embeddings | 回退到字符 bigram TF-IDF |
| 检索结果无关 | 只用向量相似度 | 加 LLM 第二层筛选 |
| 记忆无限增长 | 无遗忘机制 | 重要性+访问+时间衰减评分 |
| 合并后丢失原始信息 | 直接删除被合并记忆 | merged_from 字段记录来源 |
| jieba 词典依赖 | 外部词典可能缺失 | 字符 bigram，无需词典 |
