# 软件控制模块设计文档

> 多策略软件打开/关闭：别名直启动 → 桌面快捷方式相似度匹配 → 全盘搜索 → 兜底。中英文拼音三态匹配。

---

## 1. 设计目标

| 目标 | 说明 |
|------|------|
| 别名直启动 | 110+ 常见软件别名，秒级启动 |
| 路径直打开 | "在 D 盘打开工作" → `D:\工作` 直接打开 |
| 桌面快捷方式 | 相似度 0.6 即匹配桌面 .lnk |
| 全盘搜索 | 找不到时全盘扫描 .exe / .lnk |
| 多语言匹配 | 中文 / 英文 / 拼音 / 拼音首字母 |
| 静默启动 | 不弹 Windows 错误对话框 |
| 关闭进程 | 支持进程名 / 别名 / 拼音匹配 |

## 4. 多语言名称匹配

### 4.1 名称变体生成

```python
def _name_variants(name: str) -> List[str]:
    """生成名称的各种变体：原名称、全小写、拼音、拼音首字母、去除扩展名。"""
    variants = set()
    variants.add(name)
    variants.add(name.lower())

    base = os.path.splitext(name)[0]   # 去扩展名
    variants.add(base)
    variants.add(base.lower())

    py = lazy_pinyin(name)             # 拼音
    variants.add("".join(py))
    variants.add(" ".join(py))

    py_initials = lazy_pinyin(name, style=Style.FIRST_LETTER)  # 首字母
    variants.add("".join(py_initials))

    if base != name:
        py2 = lazy_pinyin(base)
        variants.add("".join(py2))
    # ...
```

**示例**：`_name_variants("微信")` 返回：
```
["微信", "weixin", "w x", "wx"]
```

### 4.2 综合相似度

```python
def _similarity(a: str, b: str) -> float:
    """计算两个字符串的相似度（0~1）。
    综合考虑：原文、小写、拼音三种形式的相似度，取最大值。"""
    a_variants = [a, a.lower(), a_base, a_base.lower()]
    b_variants = [b, b.lower(), b_base, b_base.lower()]
    # + 拼音形式
    a_variants.append("".join(lazy_pinyin(a_base)))
    b_variants.append("".join(lazy_pinyin(b_base)))

    best = 0.0
    for av in a_variants:
        for bv in b_variants:
            r = SequenceMatcher(None, av, bv).ratio()
            if r > best:
                best = r
    return best
```

**示例**：
- `_similarity("微信", "WeChat.exe")` → 0.0（中英不同源）
- `_similarity("微信", "微信.exe")` → 1.0
- `_similarity("weixin", "WeChat.exe")` → 0.0
- `_similarity("wx", "wx.exe")` → 1.0

## 6. 静默启动（不弹错误对话框）

### 6.1 问题

Windows 下 `os.startfile()` 找不到文件时会弹出系统错误对话框（"Windows 找不到文件"），用户体验差。

### 6.2 三层防护

```python
@staticmethod
def _startfile_silent(path: str):
    """静默启动文件，不弹 Windows 错误对话框。"""
    if os.name == 'nt':
        import ctypes
        SEM_FAILCRITICALERRORS = 0x00000001
        SEM_NOOPENFILEERRORBOX = 0x00008000
        old_mode = ctypes.windll.kernel32.SetErrorMode(
            SEM_FAILCRITICALERRORS | SEM_NOOPENFILEERRORBOX
        )
        try:
            os.startfile(path)
        finally:
            ctypes.windll.kernel32.SetErrorMode(old_mode)
```

```python
@staticmethod
def _try_start(exe_name: str) -> bool:
    """用 start 命令静默启动。"""
    # CREATE_NO_WINDOW = 0x08000000, DETACHED_PROCESS = 0x00000008
    subprocess.Popen(
        f'cmd /c start "" "{exe_name}"',
        shell=True,
        creationflags=0x08000000 | 0x00000008,
        stdout=subprocess.DEVNULL,
        stderr=subprocess.DEVNULL,
    )
```

## 7. 全盘搜索策略

### 7.1 优先目录（快速命中）

```python
def _get_fast_search_dirs(self) -> List[str]:
    """优先搜索的目录（桌面、开始菜单）。"""
    dirs = []
    home = os.path.expanduser("~")
    dirs.append(os.path.join(home, "Desktop"))
    dirs.append(os.path.join(home, "AppData", "Roaming", "Microsoft", "Windows", "Start Menu", "Programs"))
    dirs.append("C:\\ProgramData\\Microsoft\\Windows\\Start Menu\\Programs")
    dirs.append("C:\\Program Files")
    dirs.append("C:\\Program Files (x86)")
    return [d for d in dirs if os.path.isdir(d)]
```

### 7.2 深度搜索

```python
def search_file_or_app(self, keyword: str) -> Optional[str]:
    target_variants = set(v.lower() for v in _name_variants(keyword))

    # 优先目录（深度 4，快速）
    hit = self._search_in_dirs(fast_dirs, target_variants, max_depth=4)
    if hit:
        return hit

    # 全盘搜索（深度 7，超时 15s，排除系统目录）
    exclude = {
        "$Recycle.Bin", "System Volume Information",
        "Windows", "ProgramData", "Recovery", "Config.Msi",
    }
    hit = self._search_in_dirs(
        drives, target_variants, max_depth=7,
        exclude_dirs=exclude, timeout=15, prefer_exact=True
    )
    return hit
```

**匹配规则**：
- 精确匹配（变体完全相等）优先
- 模糊匹配（包含关系）
- 文件类型：`.exe`、`.lnk`、`.url`、文件夹

## 8. 关闭进程（close_app）

```python
def close_app(self, keyword: str) -> Tuple[bool, str]:
    # 1. 收集目标名称（别名 + 拼音变体）
    aliases = set(COMMON_APP_ALIASES.get(keyword, []))
    aliases.add(keyword)
    aliases.add(keyword + ".exe")
    variants = set(_name_variants(keyword))
    target_names = aliases | variants

    # 2. 遍历所有进程
    killed = []
    for proc in psutil.process_iter(["pid", "name", "exe"]):
        pname = proc.info["name"].lower()
        pexe = proc.info["exe"].lower()
        proc_variants = set(_name_variants(pname))

        if (pname in target_names
            or pbase in target_names
            or any(v in target_names for v in proc_variants)
            or any(t in pname for t in aliases if len(t) >= 3)):
            proc.terminate()   # 优先优雅终止
            killed.append(pname)

    if killed:
        return True, f"已关闭: {', '.join(set(killed))}"
    return False, f"未找到运行中的「{keyword}」进程"
```

**匹配策略**：
- 进程名完全匹配
- 进程名拼音变体匹配
- 别名子串匹配（长度 ≥ 3 避免误杀）
- `terminate()` 失败回退到 `kill()`

## 11. 踩坑记录

| 问题 | 根因 | 解决 |
|------|------|------|
| 打开"腾讯会议"弹错误对话框 | `os.startfile` 找不到文件时弹系统对话框 | `SetErrorMode` 屏蔽 + `cmd /c start` 静默 |
| "打开微信" 找不到 | 别名表不全 | 扩充到 110+ 条 |
| 中英文软件名无法匹配 | 只比原文 | 加拼音 + 首字母变体 |
| 全盘搜索太慢 | 无优先级 | 优先桌面/开始菜单，全盘限制深度+超时 |
| 关闭进程误杀 | 短关键词子串匹配（如 "qq" 命中 "qqbrowser"） | 子串匹配要求长度 ≥ 3 |
| 桌面快捷方式名称差异大 | 只支持精确匹配 | 相似度 0.6 阈值模糊匹配 |
