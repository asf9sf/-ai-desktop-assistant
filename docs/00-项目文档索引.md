# 智能助手 项目文档索引

> PyQt6 桌面智能助手：人脸识别登录 + LLM 对话 + 离线语音合成 + 软件控制 + 网页搜索 + 长期记忆

---

## 项目概述

智能助手是一个 Windows 桌面应用，集成以下能力：

| 能力 | 实现 |
|------|------|
| 人脸识别登录 | face_recognition + cv2，识别成功后欢迎动画 + 语音播报 |
| LLM 对话 | OpenAI 兼容接口，支持 Ollama / LM Studio / 自定义 |
| 离线语音合成 | Sherpa-ONNX（VITS 中文）+ pyttsx3 兜底，纯 CPU |
| 离线语音识别 | Sherpa-ONNX + SenseVoice（zh/en/ja/ko/yue），三种模式 |
| 声纹验证 | 3D-Speaker CAM++ 说话人嵌入 + 余弦相似度，单参考音频 |
| 情绪引擎 | 10 通道情绪 + OCEAN 大五人格 + 认知评估 + 交互矩阵 |
| 视觉自动化 | VLM (Vision Language Model) 驱动的屏幕感知与精准操作 |
| 流式朗读 | AI 输出时实时分句朗读，与 LLM 线程并行 |
| 软件控制 | 语音/文本指令打开桌面软件（110+ 别名） |
| 网页搜索 | Bing 搜索 + LLM 摘要 |
| 浏览器自动化 | CDP (Chrome DevTools Protocol) 驱动的 DOM 操作，B站/知乎/CSDN 搜索 |
| 音乐播放 | 网易云搜索 + 高码率下载缓存 + 系统播放器 + VIP 回退 B 站 |
| 学术搜索 | arXiv 论文检索，支持关键词/作者/ID 搜索，返回标题/摘要/PDF 链接 |
| 长期记忆 | SQLite + 向量检索，定时合并衰减 |

## 技术栈

| 层 | 技术 |
|----|------|
| GUI | PyQt6 |
| 人脸识别 | face_recognition + dlib 19.24.0 |
| TTS | sherpa-onnx 1.13.4 + sounddevice + numpy 1.26.4 |
| ASR | sherpa-onnx SenseVoice（zh-en-ja-ko-yue），int8 量化 |
| 声纹 | sherpa-onnx SpeakerEmbedding + 3D-Speaker CAM++ ONNX |
| 情绪 | emotion-engine 移植实现，纯 Python（无外部依赖） |
| LLM | requests + OpenAI 兼容 /chat/completions |
| 浏览器自动化 | Playwright (CDP) + Microsoft Edge + 单线程工作队列 |
| 音乐 | requests + 第三方网易云 API + os.startfile |
| 学术 | requests + arXiv 官方 API (Atom XML) |
| 记忆 | SQLite + numpy 向量 |
| 音频 | sounddevice（回调模式） |

**环境约束**：
- numpy 必须用 1.26.4（兼容 dlib 19.24.0，不能用 2.x）
- GPU 已被大模型占用，TTS 必须在 CPU 上运行
- Python 3.11 + conda 环境 `pythonProject2`

## 关键设计决策

### 1. 三阶段串行架构

每个阶段用独立的 `app.exec()` 事件循环，通过关闭窗口切换阶段。简单可靠，避免多窗口并发的状态管理复杂度。

### 2. TTS 回调模式播放

放弃 `sd.play/sd.wait()`，改用 `sd.OutputStream` 回调模式 + `threading.Event` 轮询。彻底解决中断后线程卡死问题。

### 3. 流式并行朗读

TTS 不等 LLM 整段回复完成，而是实时检测句子边界入队朗读。AI 还在输出时就开始语音播报，体验更自然。

### 4. TTS 资源隔离

欢迎窗和主窗口使用独立的 `TTSManager` 实例。欢迎窗结束时 `shutdown()` 释放音频设备，主窗口才能正常播放。

### 5. 音量增益在合成阶段

VITS 输出振幅偏低（~19% 满幅），在 `SherpaTTS.synthesize()` 中直接乘以增益（默认 2.5x），PCM 里就包含放大结果，避免播放环节重复处理。

### 6. numpy 1.26.4 锁定

dlib 19.24.0 不兼容 numpy 2.x（数组类型枚举值变化），必须锁定 1.26.4。

### 7. 双层意图识别（详见 03 文档）

常见指令（打开/关闭/搜索）用正则秒判，绕过 LLM；复杂指令才交给 LLM 小样本判断工具调用。兼顾响应速度与覆盖范围，避免每次都付出 LLM 延迟。

### 8. 软件控制多策略兜底（详见 04 文档）

打开软件按 成本从低到高 依次尝试：别名直启动 → 桌面快捷方式相似度匹配（0.6 阈值）→ 全盘搜索 → 兜底原始关键词。中英文拼音三态匹配（原文/小写/拼音/首字母）解决中文软件名定位问题。

### 9. 记忆分层漏斗检索（详见 05 文档）

日常检索只动轻量索引：语义匹配 Top-K → LLM 摘要筛选 → 命中后才加载原始全文。避免每次对话都加载所有记忆全文，控制 LLM 成本。向量双轨：优先 embedding API，失败回退字符 bigram TF-IDF。

### 10. 异步记忆提取

对话回复与记忆提取分离：`process()` 同步返回回复，记忆提取在后台线程进行，不阻塞用户感知的响应时间。

### 11. 语音识别 + 声纹前置过滤（详见 06 文档）

语音交互采用"录音 → 声纹验证 → 识别 → 送入 LLM"流水线。声纹验证必须在识别之前通过，防止 TTS 回放或环境声误触发。3 种模式覆盖"关闭/实时对话/唤醒词"三种使用场景，识别用 SenseVoice int8 模型，声纹用 3D-Speaker CAM++ 说话人嵌入。

### 12. 情绪作为 system prompt 背景约束（详见 07 文档）

10 通道情绪引擎独立于对话历史，以第三段 system prompt 形式注入 LLM。情绪状态由 OCEAN 大五人格决定基线、由用户输入的认知评估驱动变化、由弹性衰减回归基线，保证回复的情感一致性而不喧宾夺主。

### 13. 情绪配置的 setdefault 兼容（详见 07 文档）

旧 `settings.json` 升级时，在 `LLMClient.__init__` 用 `setdefault` 注入 6 个情绪键默认值；UI 滑块用 `to_slider_val` 辅助函数兼容"0.00~1.00 浮点"与"0~100 整数"两种存储格式，避免重启后配置丢失或错乱。

### 14. VLM 视觉自动化 (详见 08 文档)

为解决"不常见/非结构化指令"（如"关掉那个蓝色的弹窗"）的执行难题，项目引入基于 VLM 的视觉自动化模块。当文本意图匹配失败时，智能体可回退到 `VisionAutomator`，通过"Win32 截图 + VLM 坐标识别 + PyAutoGUI 执行"的链路，实现通用的桌面操作，极大扩展了智能体的能力边界。

### 15. CDP 浏览器自动化

项目引入基于 Playwright CDP (Chrome DevTools Protocol) 的浏览器自动化模块 `browser_automation.py`，与 VLM 形成互补：
- **CDP 优先**：当浏览器活跃时，所有网页操作（搜索、点击、输入）优先走 CDP DOM 操作，响应快 10~50 倍、精准度高
- **Edge 强制**：优先通过 Playwright `msedge` channel 或系统路径启动 Microsoft Edge，确保浏览器一致性
- **单线程工作队列**：Playwright 操作必须在创建浏览器的线程中执行，采用 `_work_queue` 单线程工作队列 + 任务派发模式，彻底解决跨线程 `cannot switch to a different thread` 错误
- **浏览器存活检测**：每次操作前通过 `page.url` 探测浏览器是否存活，自动恢复已崩溃的浏览器
- **搜索结果列表**：支持获取搜索结果列表（标题+链接），按编号或关键词选择视频，不再局限于"第一个"
- **VLM 兜底**：CDP 不可用时自动回退到 VLM 视觉定位，保证操作不中断

### 16. 音乐试听回退机制 (详见 09 文档)

网易云公共节点对 VIP 歌曲只返回 45 秒左右的试听片段。系统通过 `_looks_like_preview`（时长 ≤ 60 秒）自动识别试听片段，**不播放**试听，并在 B 站以"最多收藏"排序搜索"歌名+歌手"，自动点击第一个视频作为完整版的兜底方案。这避免了"播放一半就停"的用户体验问题，也不会误导用户认为系统故障。

### 17. arXiv 学术搜索快速路径 (详见 10 文档)

项目集成基于 arXiv.org 官方 API 的论文搜索模块 `arxiv_searcher.py`。通过 7 个正则模式快速识别 arXiv 搜索意图（支持"搜一下arXiv上的aigc论文"、"arxiv作者Bengio的论文"等多种表达），提取关键词后经循环清理去除冗余前缀/后缀，直接调用 arXiv API 返回真实论文数据（标题、作者、摘要、PDF 链接），不经过 LLM 推理循环，避免编造回复。支持中文分类名映射（人工智能→cs.AI、自然语言→cs.CL 等）和 `分类||关键词` 格式的组合搜索。

## 配置

所有配置在 `config/settings.json`，可通过「⚙ 设置」UI 修改：

| 配置项 | 说明 |
|--------|------|
| `llm_provider` | ollama / lmstudio / custom |
| `llm_configs` | 各 provider 的 base_url / api_key / model |
| `ai_persona` | System Prompt |
| `user_name` | 用户名（人脸识别后自动写入） |
| `tts_engine` | off / system / sherpa |
| `tts_model_dir` | Sherpa 模型目录 |
| `tts_auto_play` | AI 回复后自动朗读 |
| `tts_speaker_id` | 说话人 ID |
| `tts_volume` | 音量增益 0.1~5.0 |
| `speech_mode` | off / push_to_talk / wake_word |
| `speech_wake_words` | 唤醒词列表 |
| `voiceprint_enabled` | 是否启用声纹验证 |
| `voiceprint_threshold` | 声纹相似度阈值（0.25~0.60，默认 0.40） |
| `emotion_enabled` | 是否启用情绪引擎 |
| `personality_openness` ~ `personality_neuroticism` | OCEAN 大五人格（0.00~1.00） |
