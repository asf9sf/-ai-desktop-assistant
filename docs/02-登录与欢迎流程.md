# 登录与欢迎流程设计文档

> 人脸识别登录 → 欢迎动画 + 语音播报 → 主窗口。三阶段串行，每阶段独立 QApplication 事件循环。

---

## 1. 整体流程

```
┌─────────────────────────────────────────────────────────────┐
│  阶段 1：登录                                                │
│  LoginWindow（人脸识别）                                     │
│  ┌──────────────┐    识别成功     ┌──────────────────┐      │
│  │  摄像头预览  │ ──────────────→ │ login_success    │      │
│  │  + 识别框    │                 │   信号(name)     │      │
│  └──────────────┘                 └────────┬─────────┘      │
│                                            ↓                │
│  app.exec() 退出                          写入 user_name    │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│  阶段 2：欢迎动画                                            │
│  WelcomeWindow（无边框 + 渐变动画）                          │
│  ┌─────────────────────────────────────────────┐            │
│  │  start()                                     │            │
│  │   ├─ show() + fade_in 700ms                  │            │
│  │   └─ _play_welcome_voice() 立即播放语音       │            │
│  │       （与淡入并行）                          │            │
│  │  _on_faded_in()                              │            │
│  │   └─ _wait_voice_then_fadeout() 轮询播完      │            │
│  │       └─ fade_out 1200ms                      │            │
│  │           └─ _on_finished()                   │            │
│  │               ├─ shutdown TTS                 │            │
│  │               └─ emit finished                │            │
│  └─────────────────────────────────────────────┘            │
│  app.exec() 退出                                             │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│  阶段 3：主窗口                                              │
│  MainWindow（独立 TTSManager 实例）                          │
│  ┌─────────────────────────────────────────────┐            │
│  │  _init_tts()  创建主窗口专用 TTS              │            │

│  │  _restore_chat_history()  恢复历史            │            │

│  └─────────────────────────────────────────────┘            │
└─────────────────────────────────────────────────────────────┘
```

## 2. 入口编排（main.py）

```python
def main():
    app = QApplication(sys.argv)
    llm = LLMClient()
    recog = FaceRecognizer()

    # ---------- 阶段1：登录 ----------
    login_result = {"name": None}

    def on_login_success(name: str):
        login_result["name"] = name
        login_win.close()

    login_win = LoginWindow(recog)
    login_win.login_success.connect(on_login_success)
    login_win.show()
    app.exec()                              # 阻塞，直到登录窗关闭

    user_name = login_result["name"] or llm.settings.get("user_name", "访客")

    # 把识别到的名字写入 settings
    if user_name != "访客" and llm.settings.get("user_name", "用户") in ("用户", "", "访客"):
        llm.settings["user_name"] = user_name
        llm.save_settings()

    # ---------- 阶段2：欢迎动画 ----------
    welcome = WelcomeWindow(user_name=user_name, llm=llm)

    def on_welcome_finished():
        welcome.close()
        app.quit()                          # 退出当前事件循环

    welcome.finished.connect(on_welcome_finished)
    welcome.start()
    app.exec()                              # 阻塞，直到欢迎窗结束

    # ---------- 阶段3：主窗口 ----------
    win = MainWindow(user_name=user_name, llm=llm)
    win.show()
    sys.exit(app.exec())                    # 最终事件循环
```

**关键点**：三个阶段都用 `app.exec()` 阻塞，通过关闭窗口 / `app.quit()` 切换阶段，串行执行。

## 3. 阶段 1：人脸识别登录

### 3.1 LoginWindow

| 文件 | `ui/login_window.py` |
|------|------|
| 依赖 | `modules/face_recognition_module.py` → `face_recognition` + `cv2` + `numpy` |
| 信号 | `login_success = pyqtSignal(str)` |

### 3.2 识别流程

1. 打开摄像头，实时显示画面
2. 每帧检测人脸，与 `face_db/faces.json` 中注册的人脸编码比对
3. 命中阈值后发射 `login_success(name)` 信号
4. `main.py` 的 `on_login_success` 回调关闭登录窗，进入阶段 2

### 3.3 降级：访客模式

当 `face_recognition` / `dlib` 库不可用时：

```python
if not fr_ok:
```

## 4. 阶段 2：欢迎动画 + 语音播报

### 4.1 WelcomeWindow 设计

| 特性 | 说明 |
|------|------|
| 无边框 | `FramelessWindowHint` |
| 置顶 | `WindowStaysOnTopHint` |
| 半透明 | `WA_TranslucentBackground` |
| 圆角卡片背景 | `paintEvent` 绘制渐变圆角矩形 |
| 渐变文字 | 大字「欢迎回来，{name}」+ 蓝紫渐变 |
| 淡入动画 | 700ms，`OutCubic` 缓动 |
| 淡出动画 | 1200ms，`InCubic` 缓动 |

### 4.2 关键改进：语音与动画同步

**用户需求**：人脸识别完成后，欢迎语语音要完整播放，不被淡出打断。

**方案**：
1. `start()` 时立即开始语音播报（不等淡入）
2. 淡入完成后，轮询 `is_playing()`，等语音播完再淡出

```python
class WelcomeWindow(QWidget):
    def __init__(self, user_name: str = "用户", llm=None):
        super().__init__()
        self.user_name = user_name
        self.llm = llm
        self._tts_mgr = None
        # ...

    def start(self):
        self.show()
        # 人脸识别完成的瞬间立即开始语音播报
        self._play_welcome_voice()
        self.fade_in.start()

    def _on_faded_in(self):
        """淡入完成，等语音播报结束后再淡出。"""
        self._wait_voice_then_fadeout()

    def _wait_voice_then_fadeout(self):
        """轮询 is_playing()，播完再淡出。"""
        if self._tts_mgr is not None and self._tts_mgr.is_playing():
            QTimer.singleShot(200, self._wait_voice_then_fadeout)
            return
        QTimer.singleShot(300, self.fade_out.start)

    def _play_welcome_voice(self):
        """立即创建 TTS 并播报。"""
        from modules.tts_module import TTSManager
        s = self.llm.settings
        engine = s.get("tts_engine", "off")
        if engine == "off":
            return
        self._tts_mgr = TTSManager(
            engine=engine,
            model_dir=s.get("tts_model_dir", ""),
            speaker_id=s.get("tts_speaker_id", 0),
            volume=s.get("tts_volume", 2.5),
        )
        self._tts_mgr.speak(f"欢迎回来，{self.user_name}。")

    def _on_finished(self):
        """淡出结束，清理 TTS 资源。"""
        if self._tts_mgr is not None:
            self._tts_mgr.shutdown()       # 关键：释放音频设备
            self._tts_mgr = None
        self.hide()
        self.finished.emit()
```

### 4.3 时序图

```
t=0     start()
        ├─ show()
        ├─ _play_welcome_voice()  ← 立即开始合成 + 播报
        │   ├─ Sherpa 引擎懒加载 (~0.6s)
        │   ├─ 合成 "欢迎回来，XX"
        │   └─ sounddevice 回调播放 (~2s)
        └─ fade_in.start()        ← 同时开始淡入

t=0.7s  淡入完成 → _on_faded_in()
        └─ _wait_voice_then_fadeout()
            └─ 每 200ms 轮询 is_playing()

t=2.6s  语音播完
        └─ +300ms 停留
        └─ fade_out.start()       ← 淡出开始

t=4.1s  淡出完成 → _on_finished()
        ├─ shutdown TTS           ← 释放音频设备
        └─ emit finished
        └─ app.quit() → 进入主窗口
```

### 4.4 TTS 资源隔离

**关键设计**：欢迎窗和主窗口使用**独立的 TTSManager 实例**，避免音频设备冲突。

```
WelcomeWindow._tts_mgr  ──→ shutdown() ──→ 释放
                                            ↓
MainWindow.tts          ──→ 新实例，独占音频设备
```

欢迎窗结束时必须 `shutdown()`，否则主窗口的 TTS 无法获取音频设备。

## 5. 阶段 3：主窗口

### 5.1 TTS 初始化

主窗口创建独立的 TTSManager，配置与欢迎窗相同（都从 settings 读取）：

```python
class MainWindow(QMainWindow):
    def __init__(self, user_name: str, llm: LLMClient):
        # ...
        self._init_tts()           # 创建主窗口专用 TTS
        self._build_ui()
        # ...
```

### 5.2 主窗口不再播报欢迎语

**早期版本**：主窗口 `__init__` 末尾有 `QTimer.singleShot(1200, self._play_welcome_voice)`，会和欢迎窗重复播报。

**当前版本**：已移除该定时器，欢迎语只由欢迎窗播报一次。

```python
# main_window.py __init__ 末尾
QTimer.singleShot(100, self._refresh_all_bubbles)
QTimer.singleShot(500, self._refresh_all_bubbles)
# ❌ 已删除：QTimer.singleShot(1200, self._play_welcome_voice)
```

## 6. 用户名流转

```
face_db/faces.json  ──→  LoginWindow 识别
                                ↓
                        login_success(name)
                                ↓
                        main.py: user_name = name
                                ↓
                    ┌───────────┴───────────┐
                    ↓                       ↓
            WelcomeWindow            llm.settings["user_name"]
            显示 + 语音                    ↓
                                    config/settings.json 持久化
                                          ↓
                                    MainWindow 读取
                                    用于对话上下文
```

**写入条件**：仅当识别到的名字非"访客"，且 settings 中原 user_name 为空 / "用户" / "访客"时才写入，避免覆盖用户手动设置的名称。

```python
if user_name != "访客" and llm.settings.get("user_name", "用户") in ("用户", "", "访客"):
```

## 8. 踩坑记录

| 问题 | 根因 | 解决 |
|------|------|------|
| 欢迎语被淡出打断 | 淡出定时器固定 1.8s，语音 ~3s | 轮询 `is_playing()`，播完再淡出 |
| 欢迎语播报延迟 | 在 `_on_faded_in`（淡入完成后）才播放 | 提前到 `start()` 时立即播放 |
| 主窗口 TTS 无声 | 欢迎窗未 shutdown TTS，音频设备未释放 | `_on_finished` 中 `shutdown()` |
| 欢迎语重复播报 | 主窗口也有启动欢迎语定时器 | 移除主窗口的欢迎语定时器 |
