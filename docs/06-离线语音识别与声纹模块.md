# 离线语音识别与声纹模块设计文档

> 用 sherpa-onnx + SenseVoice 实现纯 CPU 离线语音识别，搭配 sherpa-onnx SpeakerEmbedding + 3D-Speaker CAM++ 模型实现声纹验证。三种语音交互模式 + 说话人身份校验，保证只有真人原声能触发智能体。

---

## 1. 设计理念

**语音输入必须在 CPU 上运行**：GPU 已被大模型占用，所有语音处理（ASR + 声纹）必须在 CPU 完成。

**三种交互模式，覆盖不同场景**：
- `off`：关闭语音识别，纯文字输入
- `push_to_talk`：持续监听 + VAD，自动切片识别（真正的"实时对话"，无需反复按键）
- `wake_word`：唤醒词监听，命中后完整识别并发送

**声纹验证前置**：任何语音识别结果在进入 LLM 之前，必须先过声纹校验。彻底解决 TTS 回放、电视背景音等"非真人声音"误触发问题。

**单参考音频方案**：仅保存一份 `myvoice.wav` 作为模板，简单、高效、可解释。

---

## 2. 音频参数

| 参数 | 值 | 说明 |
|------|----|------|
| 采样率 | 16000 Hz | sherpa-onnx 推荐 |
| 声道 | 1 (mono) | 语音识别不需要立体声 |
| 数据类型 | int16 / float32 | 录音用 int16，识别/嵌入用 float32 |
| 录音块大小 | 512 帧 ≈ 32 ms | 回调式录音缓冲 |

## 3. 语音识别模块 (speech_module)

### 3.1 模块结构

```
modules/speech_module.py
├── MODE_OFF / MODE_PUSH_TO_TALK / MODE_WAKE_WORD   # 模式常量
├── EMOTION_MAP / EVENT_MAP                         # 情感/事件标签映射
├── class SpeechManager                             # 语音管理器（核心）
│   ├── set_mode / get_mode                         # 模式切换
│   ├── start_recording / stop_recording_and_recognize  # push-to-talk 录音
│   ├── _start_wake_word_listening                  # 唤醒词模式启动
│   ├── _start_continuous_listening                 # 实时对话模式启动
│   ├── _continuous_listening_loop                  # VAD 切片识别循环
│   ├── _wake_word_loop                             # 唤醒词检测循环
│   ├── _recognize_audio                            # 调用 SenseVoice 识别
│   ├── _verify_voiceprint                          # 声纹验证前置
│   └── _notify_*                                   # 回调通知 UI
└── 延迟导入 helper（_try_import_sherpa_onnx 等）
```

### 3.2 三种模式的工作流程

#### push-to-talk（实时对话）

```
用户开启"实时对话"开关
    ↓
_start_continuous_listening() 启动后台线程
    ↓
_continuous_listening_loop():
    ├── 打开 sounddevice.InputStream (16kHz)
    ├── 每 0.4s 读一块音频
    ├── 计算能量（RMS），与 silence_threshold (0.02) 比较
    ├── 能量超过阈值 → 录音入 buffer
    ├── 静音连续 ≥3 块（~1.2s）且已有语音 → 切片
    ├── 切片时长 ≥ min_speech_duration (0.3s) → 送识别
    ├── 超过 10s 强制切片，避免长句丢失
    └── 切片处理：_process_listen_segment()
            ├── 声纹验证 _verify_voiceprint()
            ├── 通过 → _recognize_audio() → _notify_final()
            └── 失败 → 静默丢弃
```

#### wake_word（唤醒词对话）

```
用户开启"唤醒词对话"
    ↓
_start_wake_word_listening() 启动后台线程
    ↓
_wake_word_loop():
    ├── 低功耗监听（较小 blocksize）
    ├── 每块音频直接送入 SenseVoice
    ├── 检测识别文本中是否包含唤醒词（"小智"/"你好小智"/"小智小智"）
    ├── 命中 → 重新完整录音 → 整句识别
    ├── 声纹验证 → 通过后 _notify_final()
    └── 未命中 → 丢弃，继续监听
```

#### off

停止所有后台线程，释放音频资源。

### 3.3 SenseVoice 模型加载

```python
self._recognizer = so.OfflineRecognizer.from_sense_voice(
    model="data/model/ASR/sherpa-onnx-sense-voice-zh-en-ja-ko-yue/model.int8.onnx",
    tokens=".../tokens.txt",
    use_itn=True,                         # 启用 ITN（逆文本归一化，处理数字）
    num_threads=max(1, os.cpu_count() - 1),
)
```

**模型说明**：
- 使用 int8 量化版（`model.int8.onnx`），CPU 推理速度可接受
- 支持 中/英/日/韩/粤 五种语言
- 自带情感识别（HAPPY/SAD/ANGRY/DISGUSTED/SURPRISED/NEUTRAL）与事件检测（Applause/Laughter/Cough 等），通过 `EMOTION_MAP`、`EVENT_MAP` 映射为可读标签

### 3.4 VAD（语音活动检测）

项目未使用独立的 VAD 模型，而是基于**能量阈值**的轻量方案：

```python
chunk_float = indata.astype(np.float32) / 32768.0
energy = np.sqrt(np.mean(chunk_float ** 2))
if energy > self._silence_threshold:
    # 进入语音段
```

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `silence_threshold` | 0.02 | 能量阈值，区分静音/语音 |
| `silence_timeout` | 1.5 s | 最长静音时长 |
| `min_speech_duration` | 0.3 s | 最短有效语音，低于此直接丢弃 |
| `max_speech_duration` | 10 s | 最长单段时长，强制切片 |

**为何用能量 VAD 而非 WebRTC VAD / Silero VAD**：避免额外依赖，在 16kHz 单声道场景下能量阈值方案足够用，且可配置、跨平台一致。

### 3.5 识别结果回调链

```
SpeechManager
    ├── set_on_partial(cb)       # 实时 partial 文本
    ├── set_on_final(cb)         # 最终文本（通过声纹验证）
    ├── set_on_state_change(cb)  # 状态机事件（listening/recording/processing/idle...）
    ├── set_on_error(cb)         # 错误
    └── set_on_voiceprint_fail(cb) # 声纹验证失败专用
            ↓
UI 层 (main_window.py)
    ├── 接收 final 文本 → 送入 LLM
    ├── 接收 state 事件 → 更新 UI 指示灯
    └── 接收 voiceprint_fail → 提示"不是本人声音"
```

## 4. 声纹识别模块 (voiceprint_module)

### 4.1 技术方案

| 组件 | 模型/库 | 作用 |
|------|---------|------|
| 说话人嵌入提取 | sherpa-onnx `SpeakerEmbeddingExtractor` + `3dspeaker_speech_campplus_sv_zh_en_16k-common_advanced.onnx` | 提取 192 维说话人 embedding |
| 相似度度量 | 余弦相似度 | 比较两个 embedding 的方向一致性 |
| 参考存储 | `data/cache/voiceprint/myvoice.wav` | 单参考音频方案 |
| 默认阈值 | 0.40 | CAM++ 模型推荐的"宽松-严格"平衡点 |

模型文件路径：`data/model/SpeakerID/3dspeaker_speech_campplus_sv_zh_en_16k-common_advanced.onnx`

### 4.2 模块结构

```
modules/voiceprint_module.py
├── ENROLLMENT_TEMPLATES           # 5 条中文录音模板
├── class VoiceprintManager
│   ├── _try_load_extractor()      # 加载 sherpa-onnx SpeakerEmbeddingExtractor
│   ├── has_voiceprint()           # 检查是否已有 myvoice.wav
│   ├── enroll_voiceprint()        # 录入：录 5 秒 → 保存 → 立即验证 embedding
│   ├── verify_voiceprint(audio_data, sr, threshold)   # 核心验证（实时调用）
│   ├── verify_voiceprint_from_file(path, threshold)    # 文件验证
│   ├── verify_voiceprint_files(ref, query, threshold) # 双文件比对
│   ├── _extract_embedding(audio, sr)                  # 提取说话人向量
│   ├── _get_reference_embedding()                     # 加载参考向量（10 分钟缓存）
│   ├── _cosine_similarity(a, b)                       # 余弦相似度
│   └── _save_reference_audio / _load_audio            # 参考音频 I/O
```

### 4.3 声纹录入流程

```
用户在设置界面点击"录入声纹"
    ↓
UI 显示录音进度条（RECORD_DURATION=5 秒）
    ↓
enroll_voiceprint():
    ├── 打开 sounddevice.InputStream 录音
    ├── 5 秒后保存为 myvoice.wav（int16 / 16kHz / mono）
    ├── 立即调用 _extract_embedding() 做一次"自检"
    ├── 自检失败 → 提示用户重录
    └── 成功 → 清空 embedding 缓存（下次验证时重新加载）
```

**录音模板（避免用户念数字/短词导致 embedding 不稳定）**：
```
1. 你好，很高兴遇见你，这是我的声音
2. 我是这个智能助手的主人，请记住我的声音特征
3. 人工智能正在改变世界，语音识别技术让人机交互更加自然
4. 请帮我记住这个声音，当我说话时你能第一时间识别出是我
5. 你好小智，我是你的主人，今天天气真不错
```

### 4.4 实时验证流程（每次语音识别都会调用）

```
speech_module._verify_voiceprint(audio_data)
    ↓
检查开关（未启用/未录入 → 直接放行，不阻塞）
    ↓
音频预处理：
    ├── int16 → float32 / 32768.0
    └── 最大峰值归一化（防止音量差异影响 embedding）
    ↓
voiceprint_manager.verify_voiceprint(audio_float, 16000, 0.40)
    ↓
voiceprint_manager:
    ├── _get_reference_embedding()  # 有 10 分钟缓存
    ├── _extract_embedding(query)  # 用 SpeakerEmbeddingExtractor 提取
    ├── L2 归一化两个向量
    └── cosine_similarity(ref, query)
    ↓
阈值判断：
    similarity >= 0.40  →  通过，继续识别
    similarity <  0.40  →  失败，触发 _on_voiceprint_fail 提示
```

### 4.5 关键实现细节

#### 4.5.1 SpeakerEmbeddingExtractor 使用

```python
config = so.SpeakerEmbeddingExtractorConfig(
    model=".../3dspeaker_speech_campplus_sv_zh_en_16k-common_advanced.onnx",
    debug=False,
    provider="cpu",
    num_threads=max(1, os.cpu_count() - 1),
)
extractor = so.SpeakerEmbeddingExtractor(config)

# 流式接口
stream = extractor.create_stream()
stream.accept_waveform(sample_rate=16000, waveform=audio_float)
stream.input_finished()
embedding = extractor.compute(stream)     # 返回 numpy 数组
```

#### 4.5.2 L2 归一化 + 余弦相似度

```python
# 提取后立即归一化
norm = np.linalg.norm(result)
result = result / norm

# 相似度
similarity = np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b))
```

#### 4.5.3 参考 embedding 缓存

```python
# 10 分钟内复用，避免每次都 load + extract
if self._ref_embedding is not None and (now - cache_time) < 600:
    return self._ref_embedding
```

#### 4.5.4 异常放行策略

```python
except Exception as e:
    logger.error(f"声纹验证异常: {e}")
    return True  # 异常时放行，避免阻塞用户
```

**重要**：声纹验证的任何异常都不应阻止对话。宁可"放过"，也不要让用户说不出话。

### 4.6 阈值调优

| 阈值 | 适用场景 | 说明 |
|------|----------|------|
| 0.30 ~ 0.35 | 宽松 | 用户希望能容忍不同麦克风/口音变化 |
| **0.40** | **推荐默认** | **CAM++ 模型在 16kHz 下的常用阈值** |
| 0.50 ~ 0.60 | 严格 | 多人共用设备时防止他人冒充 |

在 `speech_module.set_voiceprint_threshold()` 中强制夹紧到 `[0.25, 0.60]`，防止误设极端值。

```python
def _on_settings_changed(self):
    self.agent.speech.set_voiceprint_enabled(self.llm.settings.get("voiceprint_enabled", False))
    self.agent.speech.set_voiceprint_threshold(self.llm.settings.get("voiceprint_threshold", 0.4))
```

## 9. 踩坑记录

| 问题 | 根因 | 解决 |
|------|------|------|
| 录音时长硬编码 3 秒 | `settings_dialog.py` 未使用常量 | 统一用 `RECORD_DURATION=5` 常量 |
| UI 阈值与内部阈值不一致 | 滑块值未乘 100 转换、保存未同步 | 加 `to_slider_val` 辅助函数 + `_on_settings_changed` 显式同步 |
| `name 'np' is not defined` | 函数内 `np` 变量未传入 | 统一使用延迟导入的 `np_module` 别名 |
| 多模板平均反而不准 | 参考音频不一致导致相似度分散 | 改为单参考音频 `myvoice.wav` |
| 播放 TTS 也被识别为本人 | 声纹验证走在识别之后、未前置 | 改为"每段音频先过声纹，再识别" |
| 配置保存后重启失效 | `llm_module.py` 未 setdefault | 在 `__init__` 中补充声纹/情绪引擎默认值 |
| 声纹验证异常阻塞对话 | 未做异常放行 | `except` 分支统一 `return True` |
| 用户念短词/数字导致 embedding 不稳定 | 参考音频太短/单一 | 提供 5 句 ≥10 字的中文模板 |
