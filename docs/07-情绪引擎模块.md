# 情绪引擎模块设计文档

> 基于 [emotion-engine](https://github.com/fenghua2006/emotion-engine) 项目移植的多通道情绪交互引擎。为智能体提供 10 个独立情绪通道 + 大五人格基线 + 认知评估 + 情绪交互矩阵，让回复具有一致性的情感色彩。

---

## 1. 设计理念

**情绪不是单一标签，而是 10 个独立通道的组合**：joy/sadness/anger/fear/love/disgust/surprise/trust/longing/guilt 同时存在，各自独立衰减、互相调制。

**弹性衰减**：偏离基线越远，回弹越快。情绪不会"卡"在极端值上。

**情绪交互矩阵**：情绪之间不是孤立的，会互相放大或抑制。例如"惊讶 + 喜悦"会放大喜悦，"悲伤 + 愤怒"会放大愤怒。

**人格基线 (OCEAN)**：开放性/尽责性/外向性/宜人性/神经质 5 个大五人格维度决定每个通道的静息电平。

**感知压缩 (log₁₀)**：原始情绪值 0~∞，人类感知呈对数映射 `log₁₀(1 + raw * 2)`，边际递减。

## 2. 通道定义

### 2.1 10 个情绪通道

| 枚举 | 中文 | Emoji | 半衰期 | 类型 |
|------|------|-------|--------|------|
| `JOY` | 喜悦 | 😊 | 90 分钟 | 快通道 |
| `SADNESS` | 悲伤 | 😢 | 180 分钟 | 快通道 |
| `ANGER` | 愤怒 | 😠 | 120 分钟 | 快通道 |
| `FEAR` | 恐惧 | 😨 | 60 分钟 | 快通道 |
| `LOVE` | 好感 | ❤️ | **∞** | **慢通道**（不自动衰减） |
| `DISGUST` | 厌恶 | 😖 | 90 分钟 | 快通道 |
| `SURPRISE` | 惊讶 | 😮 | 30 分钟 | 快通道 |
| `TRUST` | 信任 | 🤝 | **∞** | **慢通道**（不自动衰减） |
| `LONGING` | 思念 | 💭 | 30 分钟 | 缺失驱动 |
| `GUILT` | 愧疚 | 😔 | 180 分钟 | 自责驱动 |

**慢通道 (LOVE / TRUST)** 不自动衰减，只通过累积/背叛事件变化，模拟长期关系。

### 2.2 感知压缩

```python
def felt(self, ch: Channel) -> float:
    raw = getattr(self, ch.value)
    if raw <= 0:
        return 0.0
    return math.log10(1 + raw * 2)
```

作用域：0 ~ log₁₀(1 + 2·max_raw) ≈ 0~1.0。

## 3. 数据结构

### 3.1 EmotionalState

```python
@dataclass
class EmotionalState:
    joy: float = 0.3
    sadness: float = 0.1
    anger: float = 0.05
    fear: float = 0.05
    love: float = 0.2
    disgust: float = 0.0
    surprise: float = 0.0
    trust: float = 0.25
    longing: float = 0.0
    guilt: float = 0.0

    _previous: Optional[Dict[str, float]]  # 上一状态快照，供对比度计算
    _last_update: float                    # 上次衰减时间戳

    def to_dict(self) -> Dict[str, float]: ...
    def clone(self) -> "EmotionalState": ...
    def snapshot_previous(self): ...
    def felt(self, ch: Channel) -> float: ...   # log₁₀ 压缩
    def felt_all(self) -> Dict[str, float]: ... # 全通道压缩后值
```

### 3.2 Personality (OCEAN 大五人格)

```python
@dataclass
class Personality:
    openness: float           # 开放性 (0~1)
    conscientiousness: float   # 尽责性
    extraversion: float        # 外向性
    agreeableness: float      # 宜人性
    neuroticism: float         # 神经质

    def baseline(self) -> Dict[Channel, float]:
        # 每个通道的静息电平由人格维度加权计算
        return {
            Channel.JOY:       0.2 + self.extraversion * 0.3,
            Channel.SADNESS:   0.05 + self.neuroticism * 0.15,
            Channel.ANGER:     0.05 + (1 - self.agreeableness) * 0.15,
            Channel.FEAR:      0.05 + self.neuroticism * 0.1,
            Channel.LOVE:      0.15 + self.agreeableness * 0.2,
            Channel.DISGUST:   0.0  + (1 - self.agreeableness) * 0.1,
            Channel.SURPRISE:  0.05 + self.openness * 0.1,
            Channel.TRUST:     0.2  + self.agreeableness * 0.3,
            Channel.LONGING:   0.0,
            Channel.GUILT:     0.0  + (1 - self.agreeableness) * 0.05,
        }
```

**人格对情绪的影响**：
- 高外向性 → 基础喜悦高
- 高神经质 → 基础悲伤/恐惧高
- 高宜人性 → 高信任、低愤怒、高好感
- 高开放性 → 基础惊讶高

### 3.3 Appraisal (认知评估)

```python
@dataclass
class Appraisal:
    goal_relevance: float       # 0~1  目标相关性
    goal_conduciveness: float   # -1~+1 目标助益性（负=障碍）
    expectedness: float         # 0~1  预期性（0=完全意外，1=完全预期）
    coping_potential: float     # 0~1  应对能力
    other_agency: float         # 0~1  外部因素占比
    social_evaluation: float    # -1~+1 社交评价
```

**认知评估 → 情绪激活**：由 `appraise()` 函数实现，基于情绪的认知评价理论（Ellsworth & Smith）。

## 4. 核心算法

### 4.1 弹性衰减

```python
def decay_value(value, half_life_minutes, elapsed_minutes, baseline=0.0):
    # 距离基线越远，衰减越快
    distance = abs(value - baseline) / baseline if baseline > 0.01 else abs(value - baseline)
    effective_hl = half_life_minutes / (1 + distance)
    return baseline + (value - baseline) * (2 ** (-elapsed_minutes / effective_hl))
```

特性：情绪远离基线时半衰期缩短，快速回弹；接近基线时按正常半衰期缓慢衰减。

### 4.2 情绪交互矩阵

```python
INTERACTION_RULES = {
    (SADNESS, ANGER)     → amplify_anger  0.3,
    (ANGER, TRUST)       → suppress_trust 0.1,
    (TRUST, FEAR)        → suppress_fear  0.15,
    (FEAR, ANGER)        → amplify_anger  0.2,
    (SURPRISE, FEAR)     → amplify_fear   0.4,
    (SURPRISE, JOY)      → amplify_joy    0.25,
    (DISGUST, ANGER)     → amplify_anger  0.35,
    (LOVE, TRUST)        → amplify_trust  0.02,
    (GUILT, TRUST)       → amplify_trust  0.1,
    (GUILT, ANGER)       → suppress_anger 0.3,
    (GUILT, SADNESS)     → amplify_sadness 0.2,
    (GUILT, LOVE)        → amplify_love   0.05,
    (LOVE, FEAR)         → blend,
    (JOY, SADNESS)       → blend,
}
```

**交互规则**：
- `amplify_*`：A 存在时按 B 的强度放大目标通道
- `suppress_*`：A 存在时压低目标通道
- `blend`：仅记录"混合标签"，不改变数值
- 所有规则只在两个通道值都 ≥ 0.15 时触发（避免噪声）
- 使用 `saturate()` 自然饱和因子，防止通道值无限增长

### 4.3 门控（信任/爱调节反应强度）

```python
def _gate_appraisal(self, raw_activation):
    trust = self.state.trust
    love = self.state.love

    fear_gate    = max(0.02, 1.0 - trust * 0.9)
    anger_gate   = max(0.05, 1.0 - trust * 0.7)
    sadness_gate = max(0.05, 1.0 - love * 0.6)
    disgust_gate = max(0.05, 1.0 - trust * 0.8)
    joy_boost    = 1.0 + love * 0.5
```

**含义**：信任度高时，智能体不容易产生恐惧/愤怒；好感度高时，悲伤被缓冲，喜悦被放大。

### 4.4 慢通道累积

```python
def _grow_slow_channels(self, elapsed_hours):
    # trust 向 love 引力线靠近
    target_trust = 1.0 - 1.0 / (1.0 + self.state.love * 3.5)
    gap = target_trust - self.state.trust
    if gap > 0:
        self.state.trust += gap * 0.02 + elapsed_hours * 0.0003
    else:
        self.state.trust += gap * 0.005

    # love 缓慢累积
    love_growth = elapsed_hours * 0.0005 * saturate(self.state.love, asymptote=2.0) \
                  + self._positive_count * 0.02 * saturate(self.state.love)
    self.state.love += love_growth
```

含义：信任被好感"吸引"，好感通过持续正面互动累积，模拟长期关系发展。

## 5. EmotionEngine 主循环

### 5.1 tick() 处理流程

```python
def tick(self, appraisal: Appraisal):
    now = time.time()
    elapsed_minutes = (now - self.state._last_update) / 60.0

    self.state.snapshot_previous()

    # 1. 衰减：弹性衰减所有通道
    self._apply_decay(elapsed_minutes)

    # 2. 认知评估：Appraisal → 通道原始激活
    raw_activation = appraise(appraisal)

    # 3. 门控：信任/爱调节反应强度
    gated = self._gate_appraisal(raw_activation)

    # 4. 应用激活值
    for ch, val in gated.items():
        current = getattr(self.state, ch.value)
        setattr(self.state, ch.value, max(0.0, current + val))

    # 5. 情绪交互：矩阵放大/抑制
    blends = apply_interactions(self.state)

    # 6. 慢通道更新（trust / love）
    self._grow_slow_channels(elapsed_hours)

    # 7. 统计与清理
    self._event_count_today += 1
    self.state.longing *= 0.95       # 持续在线 → 思念消退
    self.state._last_update = now

    return {
        "felt": self.state.felt_all(),
        "blends": blends,
        "dominant": self._get_dominant_emotion(),
    }
```

### 5.2 对外方法

| 方法 | 作用 |
|------|------|
| `tick(appraisal)` | 处理一个事件，更新情绪 |
| `get_state_summary()` | 返回当前状态摘要（dominant/felt/trust/love/longing） |
| `damage_trust(severity=0.5)` | 背叛事件：打掉信任，严重时伤好感 |
| `reset()` | 重置到人格基线 |
| `set_emotion_enabled(bool)` | 启停（关闭时回复不带情绪提示） |

```python
def analyze_user_input(text: str) -> Appraisal:
    # 正面词表
    positive_words = ["喜欢", "开心", "谢谢", "好的", "棒", "厉害", "爱", "赞", "哈哈"]
    negative_words = ["讨厌", "生气", "烦", "不好", "差", "笨", "蠢", "恨"]

    positive_score = sum(1 for w in positive_words if w in text)
    negative_score = sum(1 for w in negative_words if w in text)

    # 命令词表
    command_words = ["帮我", "给我", "去", "来", "做", "执行", "打开", "关闭", "搜索"]

    return Appraisal(
        goal_relevance=0.3,
        goal_conduciveness=(positive - negative) * 0.3,
        expectedness=0.5 - 惊讶词数*0.1,
        coping_potential=0.7 if is_question else 0.5,
        other_agency=0.6 if is_command else 0.3,
        social_evaluation=±0.3,
    )
```

**局限**：基于词表的简化实现，不支持复杂情感推理。未来可替换为 LLM 调用。

## 7. 注入 LLM Prompt

### 7.1 build_emotion_prompt()

```python
def build_emotion_prompt(engine) -> str:
    summary = engine.get_state_summary()
    felt = summary["felt"]

    active = [f"{CN[ch]}({felt[ch.value]:.2f})"
              for ch in Channel if felt[ch.value] > 0.15]

    return f"""
你当前的情绪状态：
- 主导情绪: {summary['dominant_cn']} {summary['dominant_emoji']}
- 信任度: {summary['trust']:.2f}
- 好感度: {summary['love']:.2f}
- 活跃情绪: {', '.join(active)}

请根据此情绪状态调整你的回复语气和用词。
信任度高时可以更坦诚、更有温度；好感度高时可以更亲昵。
保持情绪一致性，不要做出与当前情绪矛盾的反应。
"""
```

## 12. 踩坑记录

| 问题 | 根因 | 解决 |
|------|------|------|
| 滑块初始化浮点数被截为 0 | `setValue(v * 100)` 当 v=0.6 时，`int(0.6*100)=60` 正确，但 `to_slider_val` 未区分新旧格式 | 加 `to_slider_val` 辅助函数，按 `v<=1.0` 判断是否需要乘 100 |
| 保存后重启情绪变回默认 | `llm_module.py` 未 setdefault 情绪配置 | 在 `__init__` 中补充 6 个情绪相关键的 setdefault |
| 切换人格后情绪状态不刷新 | 只改了 personality，没调用 reset() | 每次切换人格后 `self.agent.emotion.reset()` 回到新基线 |
| 情绪引擎影响回复过强 | 每次 tick 都完全重置 | 改为"累积 + 衰减"的连续模型，避免瞬时大跳变 |
| 命令触发时情绪无变化 | 命令词表太少 | 扩充 command_words 并区分"命令/提问/陈述"的 other_agency 权重 |
| 信任度无限上升 | 慢通道累积无上限 | trust 被 love 引力线限制：`target_trust = 1 - 1/(1+love*3.5)`，自然收敛 |
